# 💼 Portfolio Web – Jules Richardot

Ce projet est un portfolio personnel développé en HTML, CSS et TailwindCSS, avec des animations et une interface responsive. Il présente mes compétences, projets, expériences et permet de me contacter facilement.

## ✨ Fonctionnalités

- Design responsive (mobile & desktop)
- Section compétences avec visualisation par catégories
- Animation Blob 3D en arrière-plan
- Intégration GitHub et liens vers les réseaux

## 🛠️ Technologies utilisées

- HTML5  
- CSS
- Tailwind
- JavaScript  

## 📁 Structure du projet

```
/public
  /images        → Logos, photos, visuels
  /js            → Scripts JS (ex: toggle navbar, animations)
  index.html     → Page principale
  style.css      → Styles additionnels
```
